🗳️ Political Party Election Management System - Java Project
📋 Overview
The Political Party Election Management System is a Java-based application designed to simulate a simple election process. It allows administrators to manage voters and view results, while enabling voters to register and cast their votes for political parties. The system follows object-oriented programming principles and features a user-friendly interface built using Java Swing.

✨ Features
🔐 Admin Panel
Login with predefined credentials

Register new voters

View real-time election results by party

🧑‍💼 Voter Panel
Voter registration with full details:

Name

National ID

Region, Wereda, Kebele

Cast a vote for a selected political party

One vote per registered voter

📊 Election Results
Automatically updated tally of votes for each political party

Results visible only to admin

🛠️ Technologies Used
Language: Java

GUI: Java Swing (JFrame, JPanel, JButton, JLabel, JTextField, etc.)

OOP Concepts: Inheritance, Encapsulation, Polymorphism, Abstraction

Data Storage: In-memory data structures (can be extended to use file or database)

🧑‍💻 How to Run the Project
Clone or download the project files.

Open the project in an IDE (e.g., IntelliJ IDEA, Eclipse, NetBeans).

Compile and run the Main class.

On launch, select either Admin or Voter mode to proceed.
